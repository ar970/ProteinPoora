Two things have to exist in Vercel before pre-orders can be taken. Neither can live in the code: this repository is public, and Vercel has nowhere to keep orders on its own.

  1. 1

    Connect a database

    checking…

    In the Vercel dashboard, open this project, then:

    Storage → Create Database → Neon → Connect

    The free tier is far more than this needs. There is nothing to copy or paste — Vercel adds the connection details itself, and any of the usual variable names will be picked up.

  2. 2

    Set your sign-in details

    checking…

    Same project, then:

    Settings → Environment Variables → Add

    ADMIN_USERNAMEarchit
    ADMIN_PASSWORDthe password you want

    Tick all three environments (Production, Preview, Development). These are not in the code because this panel lists customers' names, phone numbers and home addresses, and anyone can read a public repository.

Already added them? Environment variables only take effect on a new deployment. Open Deployments, and on the most recent one choose Redeploy.
