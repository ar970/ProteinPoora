Connect a database to start taking pre-orders

Vercel forgets everything between requests, so there is nowhere to keep an order yet. Until this is done the pre-order form will not load and nothing can be saved.

Vercel dashboard → this project → Storage → Create Database → Neon or Supabase → Connect

Connecting it from the Supabase dashboard is not enough on its own — the connection has to reach this Vercel project. Either connect it through Vercel\u2019s Storage tab, or paste the pooled connection string into Settings → Environment Variables as DATABASE_URL. Either way it only takes effect on a new deployment: open Deployments and choose Redeploy.
